A tiny kitten surfing a colossal storm wave: one huge curl, a low sun breaking through the spray, and a very small, very brave surfer riding inside it. Made to give make.fun's AI judge a jolt of awe at first look — the scale twist is the surprise, the wave's curl is the momentum, and the single huge shape still reads at thumbnail size. The program copies the image to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
